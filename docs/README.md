# geometric_lib

Библиотека для вычисления площади и периметра базовых геометрических фигур: круга, квадрата, прямоугольника и треугольника.

## Общее описание

Каждая фигура вынесена в отдельный модуль со своими функциями `area` и `perimeter`. Для круга `perimeter` возвращает длину окружности.

| Модуль      | Фигура        | Функции             |
|-------------|---------------|---------------------|
| `circle`    | Круг          | `area`, `perimeter` |
| `square`    | Квадрат       | `area`, `perimeter` |
| `rectangle` | Прямоугольник | `area`, `perimeter` |
| `triangle`  | Треугольник   | `area`, `perimeter` |

## Описание функций

Во всех функциях значения имеют тип `float` (дробное число).

### circle

| Функция        | Что считает      | Формула      | Принимает                  | Возвращает                      |
|----------------|------------------|--------------|----------------------------|---------------------------------|
| `area(r)`      | Площадь круга    | `pi * r**2`  | Радиус `r`, тип `float`    | Площадь круга, тип `float`      |
| `perimeter(r)` | Длину окружности | `2 * pi * r` | Радиус `r`, тип `float`    | Длину окружности, тип `float`   |

Пример:

```python
area(3.0)       # 28.274333882308138
perimeter(3.0)  # 18.84955592153876
```

### square

| Функция        | Что считает       | Формула | Принимает                          | Возвращает                    |
|----------------|-------------------|---------|------------------------------------|-------------------------------|
| `area(a)`      | Площадь квадрата  | `a**2`  | Длину стороны `a`, тип `float`     | Площадь квадрата, тип `float` |
| `perimeter(a)` | Периметр квадрата | `4 * a` | Длину стороны `a`, тип `float`     | Периметр квадрата, тип `float`|

Пример:

```python
area(5.0)       # 25.0
perimeter(5.0)  # 20.0
```

### rectangle

| Функция           | Что считает             | Формула       | Принимает                                                             | Возвращает                           |
|-------------------|-------------------------|---------------|-----------------------------------------------------------------------|--------------------------------------|
| `area(a, b)`      | Площадь прямоугольника  | `a * b`       | Длину стороны `a`, тип `float`; длину стороны `b`, тип `float`        | Площадь прямоугольника, тип `float`  |
| `perimeter(a, b)` | Периметр прямоугольника | `2 * (a + b)` | Длину стороны `a`, тип `float`; длину стороны `b`, тип `float`        | Периметр прямоугольника, тип `float` |

Пример:

```python
area(3.0, 4.0)       # 12.0
perimeter(3.0, 4.0)  # 14.0
```

### triangle

| Функция              | Что считает           | Формула     | Принимает                                                                                      | Возвращает                          |
|----------------------|-----------------------|-------------|------------------------------------------------------------------------------------------------|-------------------------------------|
| `area(a, h)`         | Площадь треугольника  | `a * h / 2` | Длину основания `a`, тип `float`; высоту `h`, проведённую к основанию, тип `float`             | Площадь треугольника, тип `float`   |
| `perimeter(a, b, c)` | Периметр треугольника | `a + b + c` | Длину стороны `a`, тип `float`; длину стороны `b`, тип `float`; длину стороны `c`, тип `float` | Периметр треугольника, тип `float`  |

Пример:

```python
area(6.0, 4.0)              # 12.0
perimeter(3.0, 4.0, 5.0)    # 12.0
```
